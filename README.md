# 文献工作台(forsion-plugin-zotero)

连接**本机 Zotero 7**(localhost 本地 API,零云依赖)的文献工作台:文献浏览/检索 → 每文献阅读笔记 → 划线批注导入 → 引用块插入活动笔记。PDF 在 Zotero 里开(`zotero://` 协议),笔记与引用沉淀在 Forsion。

> 需求锚点:文献管理(Zotero)与笔记(Obsidian/Notion 系)之间的空间碎片化至今没有赢家——划线在 PDF 里、笔记在别处、引用靠手抄。本插件把三者接进同一个工作台。

本仓是 [Forsion](https://github.com/Changan-Su/Forsion)(AI 原生笔记 + 内置 Tangu Agent 的本地优先桌面工作台)的社区插件,捆绑包(bundle)形态:UI 视图 + 随包「文献工作台」Space(左文献库 + 主区笔记编辑器)。

## 安装

```bash
git clone https://github.com/Changan-Su/forsion-plugin-zotero.git
cd forsion-plugin-zotero
sh install.sh prod    # 安装到 ~/.forsion;开发家用 sh install.sh(默认 dev → ~/.forsion-dev)
```

重启 Forsion 桌面端后生效:命令面板「文献工作台:打开」,或工作台侧栏「文献工作台」Space。使用前先开 Zotero 7 → 设置 → 高级 → 勾选「允许本机其他应用与 Zotero 通信」。也可整目录压缩为单层 zip 经 Forsion 应用市场安装。

## 功能

- **文献工作台视图**(单视图两栏):
  - 左栏:连接状态卡(未连接给逐步引导)+ 集合树 + 检索框(标题/作者)。
  - 右栏:条目列表(标题/作者/年份/期刊;已有阅读笔记的条目带「笔记」徽标)→ 条目详情(元数据卡 + 摘要 + 动作)。
- **阅读笔记**:一键为文献生成 `<工作文件夹>/<引用名>.md`(无则建、有则打开),引用名 = `<首作者姓><年份>-<标题前20字符slug>`(重名自动加序号)。
- **导入划线批注**:把 Zotero 里该文献 PDF 的 highlight/note 批注追加进笔记「## 划线与批注」节。**幂等**:每条批注行尾跟 `<!-- zann:key -->` 哨兵,重复导入只增量,绝不产生重复行。
- **插入引用**:把规范引用块插到当前打开笔记的最前面(契约钉死,作者与年份之间不带空格):
  `> 作者(年). 标题. 期刊. [Zotero](zotero://select/library/items/KEY) · [[阅读笔记文件名]]`
  写作途中也可用命令「文献工作台:插入引用(检索)」呼出检索浮层,点选即插。
- **严格引文导出(BibTeX / CSL-JSON)**:三个出口 —— 详情页「复制 BibTeX」「复制 CSL-JSON」到剪贴板,列表头「导出 .bib / .csl.json」把**当前集合 / 当前检索结果**一次写成两个文件。纯本机确定性映射(不调 AI、不联网),同一批条目每次生成逐字节相同;`.bib` 的 cite key 与 `.csl.json` 的 `id` 恒同一套(见「cite key 规则」)。
- **打开 PDF**:文献带 PDF 附件时一键 `zotero://open-pdf` 唤起 Zotero 阅读(本插件不做 PDF 阅读器)。桌面宿主拦截非 http(s) 协议唤起时,自动把链接复制进剪贴板并提示(见「已知限制」)。
- **AI 读文献**(轻加值):有阅读笔记且(已导入批注或有摘要)时,把笔记文本交给 Forsion AI,产出「贡献 / 方法 / 局限」速览,写进笔记「## AI 速览」节(位于「我的笔记」之上)。禁编造:指令明确要求只依据摘要与划线。

## 用法

1. 打开 Zotero 7 桌面端 → 设置 → 高级 → 勾选「允许本机其他应用与 Zotero 通信」(默认端口 23119;改过端口到插件设置同步改)。
2. 命令面板「文献工作台:打开」→ 左栏点集合或输入检索词 → 右栏点开一条文献。
3. 「阅读笔记」建笔记 → 去 Zotero 读 PDF 划线 → 回来「导入划线批注」→ 在「## 我的笔记」节自由书写。
4. 写文章时打开你的稿子,回工作台点「插入引用」(或用「插入引用(检索)」命令),引用块直接进稿子。

## 数据存哪

- 阅读笔记:`<工作文件夹>/<引用名>.md`(工作文件夹默认「文献工作台」,插件详情页可改)。格式:
  - frontmatter:`zt_key / zt_title / zt_authors / zt_year / zt_doi`(值一律 YAML 双引号转义——带冒号/井号的论文标题是常态,裸写会拆坏属性面板解析);
  - `> [在 Zotero 中打开](zotero://select/…)` 回跳行,行尾附一份行内代码纯文本 URI 便于手动复制(桌面宿主里 `zotero://` 链接点击无效,见「已知限制」);
  - `## 划线与批注`:导入区,幂等增量(哨兵 `<!-- zann:key -->`);
  - `## AI 速览`:AI 产出区(重跑替换本节);
  - `## 我的笔记`:**自由区,导入与 AI 写入永不触碰此节以下的任何字节**。
- 引文导出产物:`<工作文件夹>/导出-全部条目.bib`(或 `导出-<集合名>` / `导出-检索-<检索词>`)与同名 `.csl.json`。文件名段恒中文常量,不随界面语言变(否则中英两套文件名会在同一个库里无限增殖)。
  - **绝不无声覆写**:内容与既有文件逐字节相同 → 不写盘,提示「已是最新」;内容变了 → 另存 `导出-…-2.bib` / `-3`,原文件一个字节不动;`.bib` 与 `.csl.json` **一起** bump(不会出现 `x.bib` 配 `x-2.csl.json` 的错配对)。
  - **读不出既有导出文件时一律中止导出**(读失败绝不当成「文件不存在」),不留半个产物;导出路径恰好是你当前编辑的文件时自动让位到 `-2`;序号 1–99 占满则报错,不兜底覆写。
- 映射索引:`<工作文件夹>/.zotero-index.json`(条目 key → 笔记路径;打开工作台时自愈,剔除指向已删文件的项)。
- 数据流向:文献元数据/批注只在本机 `localhost:<端口>` 上从 Zotero 读取,不出本机;仅「AI 读文献」把**该篇阅读笔记文本+摘要**发给你登录的 Forsion 后端。

## cite key 规则(导出的 `.bib` / `.csl.json` 用什么当键)

**基键 = `<姓><年><题首词>`**,三段直接相连、没有分隔符(例:`vaswani2017attention`)。

| 段 | 取法 | 空值兜底 |
|---|---|---|
| 姓 | 第一个 `creatorType = author` 的姓;没有 author 就取第一个有姓名的 creator(编著书取编者);单字段作者(法人)取整串 | `anon` |
| 年 | 条目日期里抓到的 4 位年 | `nd` |
| 题首词 | 标题按**空白**切出的第一个 token | `untitled` |

每段各自:转小写 → 只保留字母与数字(`\p{L}\p{N}`,其余全删)→ **按码点截前 12** → 段为空则用兜底值。

- **CJK 标题的「首词」= 整条标题**(中文标题通常没有空白 = 一个 token),所以取的是**前 12 个字**,不是第一个词语。例:`注意力机制在中文分词中的应用` → 键的第三段是 `注意力机制在中文分词中的`。
- **非 ASCII 原样保留**在键里(与字段值保留 UTF-8 是同一立场)。这类键需要 biber + XeLaTeX / LuaLaTeX;pdfLaTeX + 传统 bibtex 请自行改名。
- **同一批里撞车**(基键相同):**组内全员**加 `-a` / `-b` / `-c` 后缀(超过 26 条走 `-aa` / `-ab`),按 Zotero 条目 key 升序分配 —— 与你传给它的列表顺序无关。
- **为什么不让第一个保留裸键**:那样一来,A 单独导出时拿到裸键,后来 A 与 A′ 同批导出、而 A′ 排序更靠前时,裸键会**改指到 A′** —— 你正文里的 `\cite{裸键}` 就悄悄引到了另一篇论文。全员加后缀时,同一个陈旧引用会变成 missing reference,编译时大声报错。**宁可断,不可错指。**
- **稳定性口径**(照实说):同一批(同一次导出的同一组条目)每次生成逐字节相同;单条复制永远是裸键;**一条原本不冲突的条目,在后来某一批里出现了同姓同年同首词的邻居时会得到后缀** —— 这是 BibTeX 消歧的固有代价,不是 bug。v1 不做「key 一旦发放永不改变」的持久台账(那要引入一份新的状态机)。

**导出的字段**(空则不出;顺序钉死):

- BibTeX:`author, editor, title, booktitle, journal, publisher, school, institution, address, edition, volume, number, pages, year, doi, isbn, url, urldate`。entry type:`journalArticle→@article` / `book→@book` / `bookSection→@incollection` / `conferencePaper→@inproceedings` / `thesis→@phdthesis` / `webpage→@online` / `report→@techreport` / 其余 `→@misc`。标题里的专有名词自动 `{}` 保大小写;`url` 与 `doi` 按 biblatex 的 verbatim 语义**不转义**(只把大括号百分号编码);页码连接号归一为 `--`;DOI 归一为裸 `10.x`。
- CSL-JSON:`id / type / title / author / editor / issued.date-parts / container-title / volume / issue / page / DOI / URL / publisher / ISBN`。type 用 CSL 词表(`article-journal` / `book` / `chapter` / `paper-conference` / `thesis` / `webpage` / `report` / 其余 `document`);值保留原始 UTF-8,**不做任何 LaTeX 转义**。

## 范围说明(明确不做什么)

- 需 **Zotero 7 桌面端在本机运行**并开启本地 API;Zotero 不跑,插件只能给引导页。
- PDF 阅读/划线在 Zotero 内完成,本插件只「导入」;不做 PDF 复制进笔记库(插件无二进制写入通道)。
- 不做 **CSL 样式渲染**(APA / MLA / GB/T 7714 等成品参考文献文本)—— 那需要 citeproc 引擎,本批次禁 npm 装依赖,装不进来。导出的是 `.bib` / `.csl.json` 两种**数据格式**,成品文本交给 LaTeX / Zotero / Pandoc 去排。
- 不做 `.bib` 回导入(只出不进),不与 Better BibTeX 插件通信。
- 不做 LaTeX 音标转义:`é` 就是 `é`,不会变成 `\'e`。**含非 ASCII 的 cite key 与字段值需要 biber + XeLaTeX / LuaLaTeX**;用 pdfLaTeX + 传统 bibtex 的投稿请自行改名/改编码。`webpage` 映射到的 `@online` 也是 biblatex 的类型。
- 导出的 creator 只有 **author 与 editor** 两种;translator / series editor 等其余类型不导。摘要不进 `.bib`(完整字段清单在「cite key 规则」节)。
- 导出跟着列表走,而列表一次最多 100 条 —— 列表被截断时导出的也只有那 100 条(点导出前 UI 会先提示)。
- 引用块(插进笔记正文的那个 `> 作者(年). 标题…`)仍是可读的 Markdown 近似格式,**有意不改**成严格引文样式:它是给人读的,存量笔记里全是它。严格格式走上面的导出出口。
- 不做群组库(userID 固定 0 = 本地「我的文库」);不做批注反向写回 Zotero。
- 条目列表/检索一次最多取 100 条(v1 不翻页),超出请用检索缩小范围;集合列表同上限 100 个。
- 阅读笔记命名风格目前仅 `author-year` 一种(设置项为预留)。
- 界面中英双语,但**笔记正文与文件格式不翻译**(见「双语」节);也不做第三种语言。
- 列表里「已有阅读笔记」的标记是文字徽标「笔记」而非 page 图标:宿主图标词表只对 slash/文件类型注册面开放,插件视图内 DOM 拿不到同款 SVG,BRIEF 又禁自带图标库,故取文字徽标。

## 双语(中 / EN)

界面文案跟随宿主的语言设置(设置 → 语言),中英两套;**切语言时工作台视图不重挂也立刻跟着变**,当前选中的集合、检索词、打开的文献详情、AI 生成进度、两栏滚动位置全部保留(自检里逐条钉死)。

- 词表是 `main.js` 顶部的 `MSG = { zh, en }`,两侧键集合必须完全相等(`node check.mjs` 有断言,漏翻一条即红)。
- 「AI 读文献」的**产出语言跟随界面语言**(指令里显式声明),英文界面下速览与落款都是英文。已生成的旧速览不会被改写。
- 「收录」日期按当前语言格式化(`zh-CN` / `en-US`)。
- 占位符(`(无标题)` / `(未命名)`)在**渲染时**兜底,不在解析时烘死 —— 所以切语言即变,不必重新加载列表。
- **不随语言变的东西**(有意为之):插件 id、`localStorage` 键、默认工作文件夹名「文献工作台」、以及**阅读笔记的磁盘格式** —— `## 划线与批注` / `## 我的笔记` / `## AI 速览` 节标题、批注行格式、引用块、笔记骨架恒为中文。它们是解析锚点与幂等哨兵的宿主,跟着语言变会让存量笔记的导入幂等与「我的笔记」保护失效(自检里有一条断言钉死:两种语言下这些产物逐字节相同)。文献标题、作者、集合名等**用户数据**同样原样显示,不翻译。

#### 铁律:凡是会落到磁盘的串,一律不许调 `t()`

文件名 / `zt_title` / `zt_authors` / 引用块 / `.zotero-index.json` 里的占位文案跟着界面语言变,等于同一条文献在中英下拥有两套磁盘身份:

1. **重复笔记**:索引丢失(被同步删、换机器、用户手删)后按引用名认领笔记会认不到另一门语言建的那篇,凭空建出第二篇 —— 此后导入的划线批注与 AI 速览写进新那篇,用户写在旧那篇「## 我的笔记」里的内容再也看不到;
2. **死双链**(不需要索引丢失):还没建笔记就「插入引用」时,`[[双链]]` 用的是当时语言的名字,切到另一门语言建出的笔记名对不上 → 永久死链。

所以磁盘面的占位符钉死中文常量(`UNTITLED_DISK = '(无标题)'` / `AUTHORS_MORE_DISK = ' 等'`,与 1.0.0 存量笔记逐字节兼容),UI 面另走 `uiTitle()` / `uiAuthors()`。1.2.0 的引文导出产物同属磁盘面:文件名段(`导出` / `全部条目` / `检索` / `(未命名)`)与 `.bib` / `.csl.json` 的字节一律不随语言变,自检里把两种语言下的产物逐字节比对。加新字段时按这条分叉:**先问它会不会落盘**。自检里 `diskFace()` 那条断言专盯这个,fixture 必须覆盖占位符路径(空标题条目 + >8 作者条目),只喂有标题的正常条目会整条绕开泄漏口(1.1.0 的漏检就出在这儿)。

### 已知缺口:命令面板 / 斜杠菜单标题切语言后要重启

宿主的贡献点标题目前是**单字符串**面(`registerCommand.title` / `registerView.title` / `registerSetting.label`),没有运行时重解析 —— 插件在注册时取的是**当时**的语言。所以切换语言后:

- 命令面板里的「文献工作台:打开 / 插入引用(检索)」、视图标签页标题、插件设置页的设置项标签,**要等宿主重启才更新**;
- 工作台视图**内部**的一切文案是即时生效的,不受此影响。

这是宿主侧的已知缺口。插件不做「语言变了就重注册 / 自我 teardown」的规避 —— 那会打断已经打开的视图与进行中的导入 / AI 任务。

## 已知限制(zotero:// 协议唤起)

- **桌面宿主(Electron)里 `zotero://` 无法直接唤起**:宿主对一切 `window.open` 与外链打开只放行 http(s),其余协议一律拦截(安全闸,防页面唤起任意本机协议处理器)。表现与降级:
  - 「在 Zotero 打开 PDF」按钮:检测到被拦截(`window.open` 返回 null)时自动把 `zotero://open-pdf/…` 复制进剪贴板并提示,粘到浏览器地址栏或系统「打开方式」即可唤起 Zotero。
  - 阅读笔记里的「在 Zotero 中打开」markdown 链接、引用块里的 `[Zotero](zotero://…)` 链接:在宿主编辑器里点击无效(死链)。阅读笔记的回跳行已附纯文本 URI 供手动复制;引用块格式为数据契约钉死,未附。
  - 浏览器直跑(web 端)或系统注册了 zotero 协议的环境不受影响,`window.open` 成功即直接唤起。
  - 要在桌面宿主里打通,须改宿主主进程的协议白名单(`shell:openExternal` 只放 http(s)),那是另一件事,不在本插件范围。

## 已知限制(写入回灌)

- 阅读笔记恰好在编辑器里打开时,「导入划线批注 / AI 读文献」写盘后会自动重载该页(否则编辑器里的旧副本在你落键保存时会把导入内容抹掉)。两个残余窄缝:
  - 写入瞬间你恰有 **<400ms 未落盘的编辑**:以你的编辑为准,本次导入需重跑(数据不损坏,重导即可)。
  - **分屏**且该笔记开在非焦点面板:插件够不到其他面板,那一份仍显示旧内容,切换/重开即刷新。

## 旧宿主兼容

- `ctx.registerView / ctx.notify / ctx.activity / ctx.app.workFolder / ctx.app.readFile` 缺席的旧宿主上,插件不报错:视图/通知优雅降级(命令给提示,通知走底部吐司)。
- `ctx.getLocale / ctx.subscribeLocale`(2026-08-14 起)缺席的旧宿主上,界面**回退中文**(canonical),不订阅、不报错。
- 无块表面(`ctx.app.getPage / insertBlockAfter`)的旧宿主上,「插入引用」自动降级为「**复制引用**」(引用块进剪贴板,自己粘)。
- 老宿主没有工作文件夹设置时,产物固定落「文献工作台」文件夹。

## 真机验收项(开发期未连真机 Zotero,全部走 fixture 验证)

- [ ] 真机 Zotero 7 连接:各版本本地 API 响应形状、端口修改后的连通。
- [ ] 集合超过 25 个的库:集合树完整显示(已显式 `limit=100`;>100 个仍会截断,v1 不翻页)。
- [ ] 子对象超过 25 条的文献(划线多的精读论文):批注全部导入(已显式 `limit=100`;满 100 条会提示可能截断,v1 不翻页)。
